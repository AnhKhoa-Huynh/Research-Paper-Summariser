## [TAMPAgent: Agentic Belief-Space Planning for Mobile Manipulation](http://arxiv.org/abs/2611.03584v1)

**PDF:** https://arxiv.org/pdf/2611.03584v1
**Status:** reviewed
**Pages:** 24/31
**Coverage:** partial/truncated text

**Research question:** How to unify the open-world reasoning of Large Vision-Language Model agents with the structured constraint satisfaction of Task and Motion Planning systems under partial observability for mobile manipulation?

**Claimed contribution:** Proposing TAMPAgent, an agentic planning framework that integrates LVLMs with belief-space TAMP through hybrid beliefs combining language hypotheses and tool-certified continuous values.

**Method:** The agent formulates a partial task plan compiled by a planner into a constraint satisfaction problem, then writes a computation graph to bind the first action's parameters using perception, planning, and control tools before executing and replanning.

**Datasets/evaluation:** Simulated household tasks in MuJoCo using MolmoSpaces and RoboCasa assets, evaluated on Rainbow Y1 and Unitree G1 robot platforms in kitchen and three-room home environments.

**Baselines:** Code as Policies and Graph as Policy.

**Reported findings:** TAMPAgent achieves 77.2% absolute success on RBY1 kitchen tasks compared to 57.2% for CaP and 61.1% for GaP, while using fewer uncached input and output tokens per minute.

**Limitations/threats to validity:** The framework's guarantees depend entirely on tool and perception accuracy, and uncalibrated probabilities cause the agent to occasionally engage in redundant searching leading to timeouts.

**Reproducibility checklist:** Not reported

**Recommended follow-up experiments:** Extending the fixed domain to allow agents to dynamically add actions, incorporating calibrated probabilities for better risk awareness, and improving search efficiency.
