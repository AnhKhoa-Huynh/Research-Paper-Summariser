## [Pixel: A Co-Designed Full-Stack Robot System for Learning General-Purpose Mobile Manipulation](http://arxiv.org/abs/2611.03648v1)

**PDF:** https://arxiv.org/pdf/2611.03648v1
**Status:** reviewed
**Pages:** 16/33
**Coverage:** partial/truncated text

**Research question:** Can a co-designed full-stack robot system (Pixel) integrate hardware, scalable data collection, whole-body control, and policy learning to enable general-purpose mobile manipulation effectively?

**Claimed contribution:** We present Pixel, a co-designed, open-source mobile robot and learning stack for general-purpose mobile manipulation, combining a low-cost wheeled humanoid, multiple data-collection interfaces, a unified whole-body controller, and a common policy learning pipeline.

**Method:** Pixel uses a hierarchical system separating task-level reasoning via a vision-language model agent harness from low-level language-conditioned visuomotor control using FlowDiTX, driven by geometric fabrics for whole-body control and a relative-base action space.

**Datasets/evaluation:** The evaluation uses seven tasks with varying numbers of demonstrations: Toy Cleanup (103 human, 288 robot), Tidy Pillow (129 human, 141 robot), Trash Disposal (189 human), Vacuum Cleaning (133 robot), Hang Jacket (89 robot), Snack Retrieval (108 robot), and Wine-Glass Pouring.

**Baselines:** For hardware workspaces, Pixel is compared against YOR, AGIBOT-G1, Mobile ALOHA, RB-Y1M, and Dexmate Vega. For the gripper, it is compared against the AgileX Piper gripper. For data collection, Leader Arm, VR Joystick, and VR Body Tracking are compared against sensorized human data collection.

**Reported findings:** Policies trained from sensorized human demonstrations achieve an average task progress of 82.0% across three mobile-manipulation tasks, while policies trained from robot-teleoperated demonstrations achieve 78.7% across three additional tasks. Co-training on human and robot data further increases average task progress from 85.0% to 94.3% on Toy Cleanup and Tidy Pillow.

**Limitations/threats to validity:** Not reported

**Reproducibility checklist:** The authors state that the platform can be assembled for under $15,000, use exclusively off-the-shelf parts, and provide code and designs at https://pixel-robot.com/pixel.

**Recommended follow-up experiments:** Future work could explore extending the sensorized human data collection system to more complex, dexterous tasks as described in the companion paper Pixel-UMI.

## [KlaskTron: An Open-Source Platform for Physical Adversarial Multi-Agent RL](http://arxiv.org/abs/2611.03138v1)

**PDF:** https://arxiv.org/pdf/2611.03138v1
**Status:** reviewed
**Pages:** 10/10
**Coverage:** full extractable PDF text

**Research question:** How to design, simulate, and transfer physical adversarial multi-agent reinforcement learning policies to an open-source, low-cost desktop-scale robotic testbed based on the game KLASK?

**Claimed contribution:** The authors introduce KlaskTron, an open-source, low-cost (<$2500 USD) desktop-scale robotic testbed for adversarial MARL, complete with hardware CAD/BOM, an Isaac Lab GPU-native digital twin, a validated sim-to-real baseline using a learned neural actuator model, and public software releases.

**Method:** The method involves vision-based state estimation using an Extended Kalman Filter with adaptive process noise, GPU-native simulation in NVIDIA Isaac Lab, a learned 3-hidden-layer MLP neural actuator model capturing motor dynamics from 37,500 time-series samples, and PPO training with a time-decaying reward curriculum and Enhanced Self-Play.

**Datasets/evaluation:** The datasets consist of 37,500 time-series samples (approximately 12.5 minutes at 50 Hz) collected from physical system trajectories (circles, diagonals, linear sweeps) with commanded velocities up to plus or minus 0.7 m/s to train the neural actuator model, alongside evaluation over a 10-game human-robot series.

**Baselines:** Not reported

**Reported findings:** The transferred baseline policy achieved a 10 percent win rate against a recreational human opponent over a 10-game series, with an average episode duration of 31.3 seconds, 7.4 defensive blocks, 5.0 offensive strikes, 1.8 goal-directed hits, and 43.6 percent possession.

**Limitations/threats to validity:** The policy experienced an offensive action mismatch where strikers missed the ball by 0.5 to 1.5 cm due to magnetic coupling lag, gantry damping, and EKF position uncertainty.

**Reproducibility checklist:** All project assets including hardware CAD/BOM, assembly documentation, inference software stack, simulation, and MARL setup are released publicly via GitHub repositories.

**Recommended follow-up experiments:** Future work includes reintroducing magnetic biscuit obstacles for a non-convex landscape, extending to four-agent play via round-Klask, exploring autonomous representation learning to move past hand-engineered features, and integrating game-theoretic approaches approximating Nash equilibria.
