## [Reasoning on Call: Efficient Agentic Robot Control for Long-Horizon Robot Manipulation](http://arxiv.org/abs/2611.26341v1)

**PDF:** https://arxiv.org/pdf/2611.26341v1
**Status:** reviewed
**Pages:** 9/9
**Coverage:** full extractable PDF text

**Research question:** How to perform efficient agentic robot control for long-horizon manipulation without incurring the excessive latency and token costs of frequent model calls?

**Claimed contribution:** We propose RoC (Reasoning on Call), an efficient framework that couples an online task-state monitor with event-triggered agent review to coordinate a low-level policy and a reasoning agent for execution repair and plan revision.

**Method:** RoC uses an online task-state monitor initialized from Robometer to jointly estimate subtask progress, predict transition requests, and propose next goals using stage-aware visual context and ordered interaction memory. Progress anomalies, transition requests, and critical contact events trigger agent review to execute prefix shortening, local refinement, subtask takeover, transition rejection, or successor revision.

**Datasets/evaluation:** RMBench simulation benchmark and three real-world long-horizon manipulation tasks on the SO-ARM101 platform (Drawer Sorting, Cover and Reveal, and Tabletop Cleanup).

**Baselines:** Direct control and hybrid control in GPT-as-Policy, alongside seven policy-based baselines including X-VLA, FastWAM, pi_{0.5}, MemoryVLA, Mem-0, EventVLA, and MemoryWAM.

**Reported findings:** On RMBench, RoC improves task success rate to 99.6% (outperforming GPT-as-Policy by 24.0 percentage points and MemoryWAM by 15.1 percentage points) while reducing token consumption by 65.3% compared to the strongest agent-based baseline. In real-world experiments, RoC achieves an overall success rate of 73.3%.

**Limitations/threats to validity:** Failures primarily involve difficult grasps that remain unsuccessful despite agent intervention because the current reasoning agent fails to translate visual evidence into effective grasp corrections.

**Reproducibility checklist:** The paper provides detailed framework descriptions, mathematical formulations, training objectives, and implementation hyperparameter settings, but does not provide an open-source code repository link.

**Recommended follow-up experiments:** Investigate integrating stronger visually grounded manipulation reasoning models into the framework to further improve recovery performance without redesigning the core control architecture.

## [Dynamic Human-Robot Role Allocation through Entropy-Based Monitoring and LLM Reasoning](http://arxiv.org/abs/2611.26090v1)

**PDF:** https://arxiv.org/pdf/2611.26090v1
**Status:** reviewed
**Pages:** 10/10
**Coverage:** full extractable PDF text

**Research question:** How can dynamic role allocation in human-robot collaboration be designed to promote both intuitiveness and human agency while allowing users to take initiative?

**Claimed contribution:** A dynamic role allocation framework combining a cost-driven Behavior Tree architecture, Shannon entropy-based online human activity monitoring, and LLM-interpreted natural language user preferences.

**Method:** The framework uses a modified Behavior Tree with a Cost-Based Fallback node that dynamically reorders available activities using a cost vector derived from task models, history, LLM-processed natural language preferences, and distance-based tracking.

**Datasets/evaluation:** A Tangram assembly task using a human-shaped silhouette and a tree silhouette involving 14 participants in a multi-subject experiment.

**Baselines:** A baseline approach where both the human and the robot receive explicit task assignments simultaneously through a graphical user interface without user-driven flexibility.

**Reported findings:** Condition A (the proposed framework) yielded significantly higher ratings for robot action predictability and clarity, significantly lower frustration levels, and reduced both task execution time and human idle time compared to the baseline.

**Limitations/threats to validity:** The current LLM instruction handling is tailored to the Tangram assembly task with easily identifiable semantic attributes, and the task model assumes each activity is executed at most once with purely enabling dependencies.

**Reproducibility checklist:** The task models, perception setups (SAM 2, RealSense D435i), cost formulations, and experimental parameters (such as distance thresholds and temporal windows) are detailed, and a multimedia attachment link is provided.

**Recommended follow-up experiments:** Extending the approach to real-world assembly scenarios with less distinguishable components, supporting richer task representations with complex dependencies, and incorporating human-aware motion planning.
