## Summary / source snapshot

The authors introduce Gamer, a generalist agent framework designed for long-horizon tasks across complex 2D and 3D interactive environments. The system combines perception, memory management, and multi-step reasoning within an end-to-end architecture supported by a cloud-edge inference engine.

## Method / approach

Continued pre-training on tens of thousands of hours of device-level keyboard and mouse interaction trajectories, followed by sparse-thinking instruction tuning and a stable multi-turn reinforcement learning method.

## Reported contribution / result

The authors claim Gamer demonstrates solid generalization and operational efficiency comparable to skilled players in 3D open-world games, alongside competitive results on 2D game benchmarks.
