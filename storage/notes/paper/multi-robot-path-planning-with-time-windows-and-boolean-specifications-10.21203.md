## Summary / source snapshot

The authors propose a unified planning framework to address the combinatorial challenges of multi-robot path planning under complex logical specifications and temporal constraints. By combining a Mixed-Integer Linear Programming model with a Beam Search-based heuristic, the approach aims to balance computational efficiency and solution quality.

## Method / approach

Formulation of the problem as a Mixed-Integer Linear Programming model incorporating logical dependencies, timing requirements, and collision avoidance, alongside a Beam Search-based heuristic algorithm utilizing a similarity-based filtering mechanism for scalability and diversity.
