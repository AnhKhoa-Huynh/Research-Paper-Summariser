## Summary / source snapshot

The authors propose Objectives as Policies, a framework that integrates pretrained vision-language models with model-predictive controllers for contact-rich robotic manipulation tasks. The approach utilizes editable objective programs generated by the vision-language model and executed via simulation-based planning before real-world deployment.

## Method / approach

The authors introduce a framework where a pretrained vision-language model generates an editable objective program comprising sequential task stages, combining cost functions and completion conditions. This program is executed through a shared sampling-based model-predictive controller using a simulation-based digital twin, and is iteratively updated based on rollouts prior to real-world deployment.

## Reported contribution / result

The authors claim that their framework outperforms strong baselines across four tabletop manipulation tasks evaluated in both simulation and the real world.
