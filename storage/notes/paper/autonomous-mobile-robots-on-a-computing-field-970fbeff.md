## Summary / source snapshot

The authors introduce CABOT, a computational model where autonomous mobile robots operate on an active cellular automaton grid rather than a passive plane. This approach shifts the computational burden from strengthening the individual robots to enhancing the environment.

## Method / approach

The authors define a model where weak, oblivious, and myopic robots interact with a grid whose cells evolve synchronously through finite states, and they validate additional rule sets using simulation.

## Reported contribution / result

With a small number of field states, the proposed model enables weak robots to achieve tasks such as line formation, gathering from arbitrary configurations, grid and torus exploration, pattern filling, and maze navigation.

## Limitations / evidence gaps

Certain tasks like gathering and line formation from arbitrary configurations cannot be solved field-silently with any number of states, and some rule sets are validated by simulation only.

## Why it might matter

It establishes that strengthening the environment with a cellular automaton can compensate for extreme minimalism in robot capabilities, offering a new resource measure for multi-robot systems.
