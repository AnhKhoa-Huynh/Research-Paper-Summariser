## Summary / source snapshot

The authors introduce FlexMARL, a graph-driven framework designed to co-design rollout and training for large-scale multi-agent reinforcement learning using large language models. The system addresses infrastructure limitations such as topology-induced rollout skew, synchronization barriers, and dynamic training demands through a centralized data hub and specialized execution engines.

## Method / approach

The framework utilizes a multi-agent execution graph and a decentralized intermediate storage called the MEG Store, alongside a Rollout Engine for dependency parallel sampling, a Joint Orchestrator for asynchronous pipelining, and a Training Engine for on-demand resource allocation and location-agnostic state swapping.

## Reported contribution / result

Empirical evaluations on a production cluster demonstrate that FlexMARL achieves up to a 7.3x speedup and improves hardware utilization by up to 5.6x compared to existing frameworks.
