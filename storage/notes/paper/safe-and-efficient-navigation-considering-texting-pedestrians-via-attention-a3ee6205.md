## Summary / source snapshot

The authors propose an attention-aware navigation framework that classifies pedestrians as attentive or distracted using 3D skeletal features and a Random Forest classifier. This system dynamically adjusts cost-map safety margins around distracted individuals to enable proactive robot avoidance.

## Method / approach

Real-time pedestrian attention classification using 3D skeletal features and a Random Forest classifier, combined with dynamic widening of cost-map safety margins around distracted individuals, evaluated via a within-subjects user study with 12 participants across 252 trials.

## Reported contribution / result

The framework significantly improves perceived smoothness and predictability compared to a LiDAR-only baseline and a trajectory-prediction-only method, without increasing travel time.
