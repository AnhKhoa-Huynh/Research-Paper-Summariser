## Summary / source snapshot

This paper investigates how non-experts interpret performance evaluations of robot learning systems, specifically examining metrics like task success rates. The authors conducted a user study using real evaluation data, failure case descriptions, and videos to understand how novices assess robot capabilities and risks.

## Method / approach

A user study in which participants viewed real evaluation data, including task success rates, failure case descriptions, and videos from multiple published robot learning projects.

## Reported contribution / result

Non-experts use task success rates in a manner consistent with expert expectations, place high value on unreported failure cases, and desire access to both historical evaluation data and robot-generated performance estimates for novel tasks.
