## Summary / source snapshot

The authors introduce Pixel, a co-designed full-stack system intended for learning general-purpose mobile manipulation. The approach integrates hardware, data collection interfaces, control, and policy learning into a single framework to avoid system mismatches.

## Method / approach

The system combines a low-cost wheeled humanoid with human-aligned kinematics, compliant grippers, multiple teleoperation and human data-collection interfaces, a unified whole-body controller, a common policy learning pipeline, and a hierarchical learning stack for language-conditioned visuomotor control and long-horizon task execution.

## Reported contribution / result

The authors demonstrate mobile-manipulation behaviors that require dexterity, active perception, navigation, and whole-body coordination across hardware, data collection, and policy learning.
