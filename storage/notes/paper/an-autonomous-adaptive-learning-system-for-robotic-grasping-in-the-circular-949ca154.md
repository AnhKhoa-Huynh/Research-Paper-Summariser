## Summary / source snapshot

This paper introduces an autonomous grasp learning framework tailored for robotic grasping within variable circular manufacturing environments. The proposed system explicitly separates different types of uncertainty and integrates active perception with human demonstration data to handle unstructured conditions.

## Method / approach

The framework distinguishes between aleatoric and epistemic uncertainty, utilizes vision-language models for semantic and spatial scene understanding, employs view planning for active perception, and leverages large-scale human demonstration data to learn interaction patterns.
