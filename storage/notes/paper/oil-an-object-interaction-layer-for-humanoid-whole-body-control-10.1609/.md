## Summary / source snapshot

The authors present an Object Interaction Layer that extends whole-body control interfaces for humanoid robots to include object motion and contact. This system translates object-centric commands into coordinated movements while preserving balance, enabling diverse interactions without task-specific retraining.

## Method / approach

Augmenting a standard whole-body controller with object-centric commands to translate desired object motion and contact into coordinated whole-body behavior.

## Reported contribution / result

Object-level commands improve performance over robot-centric controllers while matching task-specific policies across object property variations, alongside demonstrating zero-shot generalization and sim-to-real transfer on the Digit humanoid robot.
