## Summary / source snapshot

The authors propose Physically Grounded Execution (PGX), a framework designed to help vision-language-action models handle long-horizon humanoid loco-manipulation tasks. The approach separates temporal and precision control from the VLA using classical components to improve stage progression and task success.

## Method / approach

The framework decomposes tasks into three layers: a predicate-based state machine for task progression, VLA skills operating within active manipulation phases, and world-coordinate locking for spatial consistency.

## Reported contribution / result

The authors demonstrate through experiments on three simulated tasks and one real-world task using a Unitree G1 humanoid robot that PGX improves stage progression and task success rates for long-horizon loco-manipulation.
