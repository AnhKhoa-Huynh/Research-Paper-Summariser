## Summary / source snapshot

The authors introduce a unified framework called CHIP for learning reusable physics-based humanoid interaction skills from heterogeneous motion data. The method uses a conditional interaction prior to model context-dependent skills and supports various tasks such as scene-aware locomotion and contact-rich manipulation.

## Method / approach

A three-stage training approach consisting of learning physics-based motion-imitation policies to acquire teacher behaviors, distilling these behaviors into a context-conditioned interaction prior within a shared discrete space, and initializing downstream task policies followed by prior-regularized online RL post-training.

## Reported contribution / result

The approach supports scene-aware locomotion, contact-rich object manipulation, and compositional behaviors like environment-aware object transport and long-horizon skill sequencing, yielding smooth transitions and physically plausible motion.
