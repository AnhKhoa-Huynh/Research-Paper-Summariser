## Summary / source snapshot

The paper investigates haptic shared control strategies to facilitate human operation of multi-robot systems. It combines a modified global connectivity maintenance algorithm with three adaptive supervision strategies enabling varying scales of user control.

## Method / approach

The authors propose modifying a global connectivity maintenance algorithm to use local frame measurements from sensors with limited fields of view, paired with single agent, pinning, and centroid control strategies alongside haptic feedback, and evaluated these approaches using a user study across multiple scenarios.
