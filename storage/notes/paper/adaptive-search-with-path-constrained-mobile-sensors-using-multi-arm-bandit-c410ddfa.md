## Summary / source snapshot

The authors examine a constrained sequential decision problem involving teams of energy-limited mobile sensors detecting areas of interest through noisy online measurements. They formulate the active path selection as a multi-armed bandit problem and introduce an iterative search algorithm that adaptively assigns paths based on data-driven confidence bounds.

## Method / approach

Formulating active path selection as a multi-armed bandit problem, utilizing an iterative search algorithm that assigns paths via confidence bounds from collected data, and applying a graph-based method to construct low-cardinality path covers.

## Reported contribution / result

The authors establish finite-time and anytime probabilistic correctness guarantees for the algorithm, derive non-asymptotic upper bounds for detection and labeling times that match algorithm-independent lower bounds up to constant factors, and illustrate performance effects using numerical simulations.
